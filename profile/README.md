# open-smartphone-commons

This work lives on as **[linux-phone-oco](https://github.com/linux-phone-oco)**: Linux phones as good
as Android and iOS, or better - shown with evidence. Its research (Open Handset Commons) is in
[linux-phone-oco/docs](https://github.com/linux-phone-oco/docs), and the live comparison is at
[linux-phone-oco.github.io/docs](https://linux-phone-oco.github.io/docs/).
